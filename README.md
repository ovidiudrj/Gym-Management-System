# 🏋️‍♂️ FitZone+ Gym Management System

A console-based software built using **Java** to manage the internal operations of a fitness center. 

It was designed to showcase foundational software design concepts, including complex class interactions, abstraction, encapsulation, and clean data modeling.

###  Key Features

*  **Interactive Console Workspace:** Navigate through a comprehensive menu to add client registrations, manage trainers, update pricing dynamically, or generate reports.
*  **Subscription Management:** Supports distinct Standard and Premium subscriptions. The system dynamically calculates pricing using abstract classes and method overriding.
*  **Personnel & Trainer Routing:** Add trainers as either full-time employees or external part-time collaborators. Each trainer is securely linked to specific specializations using Enums for type-safety.
*  **Dynamic Workouts:** Create distinct workout classes (e.g., Yoga, CrossFit, Pilates) parameterized by Base Price and Intensity Level (Easy, Medium, Hard).
*  **Automated Reporting:** Generates an immediate summary report mapping all available workout types to their qualified, assigned trainers.
